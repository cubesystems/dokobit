# Dokobit API Integration Package

[![Tests](https://github.com/cubesystems/dokobit/actions/workflows/tests.yml/badge.svg)](https://github.com/cubesystems/dokobit/actions/workflows/tests.yml)

Generic Dokobit API integration package for Laravel applications.

## Features

- Authentication API client
- Signing API client
- Type-safe DTOs using Spatie Laravel Data
- Enum-based status handling

## Installation

Requires PHP 8.4 or later and Laravel 11.x, 12.x, or 13.x.

```bash
composer require cubesystems/dokobit
```
